📊 Visão Geral do Projeto

Datathon MLet é uma plataforma integrada de aprendizado de máquina e inteligência artificial para previsão de ações em bolsa de valores. Combina MLOps moderno, múltiplos frameworks de ML e um sistema RAG para análise contextualizada.

✨ Principais Características:
✅ 3 Modelos ML (PyTorch, TensorFlow, Scikit-Learn)
✅ Sistema RAG para Análise Contextual
✅ Pipeline Reprodutível com DVC
✅ Rastreabilidade Total com MLflow
✅ API REST + Dashboard Interativo
✅ Containerização Completa
🤖

Machine Learning

3 modelos complementares treinados em dados de bolsa, validados com múltiplas métricas.

🧠

Inteligência Artificial

Sistema RAG que fornece recomendações contextualizado sem alucinações.

⚙️

MLOps Completo

DVC + MLflow garantem reprodutibilidade, rastreabilidade e governança.

🐳

Cloud-Native

Containerizado com Docker, pronto para AWS/GCP/Azure.

📡

API Moderna

FastAPI com uvicorn, endpoints para previsão e análise.

📊

Dashboard

MLflow UI mostra todos os experimentos, métricas e histórico.

🚀 Quick Start

Para Desenvolvedores

cd datathon-grupo-05

# Setup local
python -m venv venv
venv\Scripts\activate
pip install -r requirements_local.txt

# Executar pipeline
dvc repro

# Iniciar API
docker-compose up api
# Acesse: http://localhost:8000/docs

# Ver experimentos
docker-compose up mlflow
# Acesse: http://localhost:5000

Para Apresentações

1. Ler sumário executivo 2. Ver template de slides 3. Documentação técnica

Exemplos de API

// Previsão de ações
POST /predict
{
  "ticker": "PETR4",
  "model": "pytorch",
  "days_ahead": 5
}

// Query RAG
POST /ask
{
  "query": "Quais ações recomendar em 2026?"
}

// Status
GET /health
